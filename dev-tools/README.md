# Developer Tools & Productivity

The everyday, general-purpose software that makes security work faster: editors,
terminal multiplexers, and a grab-bag of utilities for editing, comparing,
diagramming, and unpacking things. Not attack tools — the workbench you keep
them on.

## Tools

| Tool | Summary |
| --- | --- |
| [Visual Studio Code](vscode.md) | Free, extensible code editor for notes, scripts, and tooling |
| [Git](git.md) | Version control — clone tools, track your scripts and notes, roll back safely |
| [CyberChef](cyberchef.md) | The "cyber swiss-army knife" for encoding/decoding, crypto, and data ops |
| [jq](jq.md) | Command-line JSON processor for API output and JSON-emitting tools |
| [tmux](tmux.md) | Terminal multiplexer — many shells in one window, sessions that survive disconnects |
| [Misc utilities](misc-utilities.md) | Arduino IDE, DB Browser for SQLite, draw.io, MobaXterm, WinMerge, 7-Zip, Notepad++ |
