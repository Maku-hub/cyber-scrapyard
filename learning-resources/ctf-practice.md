# CTF & Practice

Capture-the-flag events and vulnerable-by-design practice targets — the fastest
way to build offensive skills by doing. See also the guided platforms in
[Platforms & Creators](platforms-and-creators.md).

## Where to compete & find events

- [CTFtime](https://ctftime.org) — the calendar and team ranking hub for CTF
  competitions worldwide; also archives write-ups. Start here to find events at
  your level.

## Vulnerable machines & self-hosted targets

- [VulnHub](https://www.vulnhub.com) — free downloadable vulnerable VMs you run
  locally for boot-to-root practice; great for offline labs.

## Guided / beginner-friendly practice

- [picoCTF](https://picoctf.org) — free, beginner-focused CTF platform and
  year-round practice ("gym") from Carnegie Mellon; ideal first CTF.
- [PentesterLab](https://pentesterlab.com) — hands-on exercises focused on web
  exploitation and code review, with a structured learning path (free and
  pro).
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) —
  free, excellent web-vulnerability labs (also listed in
  [Platforms & Creators](platforms-and-creators.md)).

## Notes

- Read other players' **write-ups** after each challenge (CTFtime links many) —
  that's where most of the learning happens.
- Keep notes and scripts under version control with [Git](../dev-tools/git.md),
  and lean on [CyberChef](../dev-tools/cyberchef.md) for the encoding/crypto
  stages that show up constantly.
