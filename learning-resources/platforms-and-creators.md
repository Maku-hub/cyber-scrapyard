# Platforms & Creators

Where to get hands-on practice, and who to learn from.

## Practice platforms

- [TryHackMe](https://tryhackme.com) — guided paths and rooms, very
  beginner-friendly.
- [Hack The Box](https://www.hackthebox.com) — machines and CTF challenges,
  from easy to expert.
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) —
  free, excellent, hands-on web vulnerability labs.
- [OverTheWire](https://overthewire.org/wargames/) — classic wargames for
  Linux/shell and fundamentals.
- [CryptoHack](https://cryptohack.org/) — learn cryptography by breaking it.
- [roadmap.sh — Cyber Security](https://roadmap.sh/cyber-security) — free
  interactive skill-path map for planning what to learn next.

## Creators

Aggregated directory of channels: [Security Creators](https://securitycreators.video).

- [Gynvael Coldwind](https://www.youtube.com/@GynvaelEN) — low-level security,
  CTF, reverse engineering.
- [John Hammond](https://www.youtube.com/@_JohnHammond) — malware analysis, CTF,
  tooling.
- [LiveOverflow](https://www.youtube.com/@LiveOverflow) — binary exploitation,
  web security, RE.
- [IppSec](https://www.youtube.com/@ippsec) — detailed Hack The Box machine
  walkthroughs.
- [HackerSploit](https://www.youtube.com/@HackerSploit) — pentesting, Linux,
  tooling.
