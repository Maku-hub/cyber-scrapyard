## How to use this section

If you're **just starting**, work top-down: read the fundamentals
([Books](books.md)), follow a [certification](certifications.md) track for
structure, and practice constantly on the [platforms](platforms-and-creators.md).
If you're **already working in the field**, treat this as a curated set of
pointers to fill gaps and keep up.
