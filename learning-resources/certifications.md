# Certifications

A suggested certification path — one of the clearest, most practical sequences
for most beginners and intermediate learners. It is **not** the only route:
cybersecurity is huge, and everyone eventually picks a direction (offensive,
blue team, cloud, governance, forensics, management).

> For the full landscape of certifications and possible paths, see the
> excellent [Security Certification Roadmap](https://pauljerimy.com/security-certification-roadmap/)
> — a comprehensive, interactive map of nearly every certification on the market.

## Stage 1 — Fundamentals

- **CompTIA Network+** — the most popular entry-level networking cert;
  essential groundwork for security.
- **CompTIA Security+** — the standard first security certification; often the
  minimum for junior roles.

## Stage 2 — Core skills (pick a track)

### Track A — Offensive / pentesting

- **eJPT (INE / eLearnSecurity Junior Penetration Tester)** — one of the best
  beginner-friendly, hands-on pentest certs.
- **Burp Suite Certified Practitioner (BSCP)** — deep web application
  vulnerability knowledge and the right mindset to exploit them.
- **PNPT (TCM Security Practical Network Penetration Tester)** — very practical,
  including real-world reporting.
- **OSCP (Offensive Security Certified Professional)** — the gold standard for
  pentesters; hands-on and demanding.

### Track B — Blue team / defense

- **CompTIA CySA+** — security analytics, monitoring, threat detection.
- **eCDFP / eCIR / eCTHP (eLearnSecurity, now INE Security)** — practical
  blue-team certs.
- **GCIA / GCED / GCIH (SANS GIAC)** — top-tier defensive certs; expensive but
  elite.

### Track C — Cloud security

- **Foundations:** Microsoft Azure Fundamentals, AWS Certified Cloud
  Practitioner.
- **AWS Security Specialty** — best starting point for cloud-focused security.
- **Microsoft SC-200 / SC-300 / SC-400** — incident response, identity, and
  compliance in the Microsoft ecosystem.
- **CCSP (ISC2)** — advanced cloud security governance and architecture; highly
  regarded.

## Stage 3 — Senior & management

- **CISSP (ISC2)** — widely considered the most prestigious security cert;
  requires significant experience.
- **CISA (ISACA)** — for audit, compliance, and risk-focused roles.
