# OSINT Framework

> A curated, browsable directory of OSINT resources organised by data type —
> a starting map for "where do I even look?".

- **Link:** https://osintframework.com (source: https://github.com/lockfale/OSINT-Framework)
- **Type:** open source (free web service)
- **Platform:** web app

## Description

OSINT Framework is a giant, categorised tree of free OSINT tools and websites.
Start from what you have — a username, email, domain, phone number, image, IP
address — and drill down through branches to the specific services that work on
that data type. It doesn't do the investigating for you; it's a reference that
saves you from remembering hundreds of individual sites and helps you discover
resources you didn't know existed. Keep it open as a companion while you work.

## Usage examples

```text
# 1. Open https://osintframework.com
# 2. Pick the branch matching your starting data (e.g. "Username" or "Email Address")
# 3. Expand sub-categories to narrow down (e.g. Email > Breach Data)
# 4. Click a leaf node to open the external tool/site in a new tab
#    (a (T) marker means it's a tool to install, (D) means it needs a domain, etc.)
# 5. Cross-reference finds back into your own notes or a link-analysis tool
```

## Notes & references

- Legend: `(T)` requires a downloadable tool, `(D)` shows a Google-dork example,
  `(R)` requires registration, `(M)` indicates a URL you edit manually.
- It's a directory, not a scanner — pair it with hands-on tools like
  [theHarvester](theharvester.md), [SpiderFoot](spiderfoot.md), and
  [Maltego](maltego.md).
- Community-maintained on GitHub; some external links go stale, so verify before
  relying on any single entry.
- A comparable curated list: https://github.com/jivoi/awesome-osint
