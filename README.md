# Notatki o cyberbezpieczeństwie

To repozytorium zawiera zbiór **notatek, zasobów i odnośników związanych z cyberbezpieczeństwem**.

> ⚠️ **Uwaga:** treść jest **robocza, surowa i miejscami nieuporządkowana**.

Traktuj to repo jak **osobisty notatnik i materiał referencyjny**. Notatki mogą być niekompletne, miejscami się powtarzać i być w trakcie obróbki. Z czasem są **sortowane, czyszczone i porządkowane**.

## Spis zawartości

- [Books.md](Books.md) — polecane książki o cyberbezpieczeństwie
- [Certification.md](Certification.md) — proponowana ścieżka certyfikacji
- [Platforms_and_Creators.md](Platforms_and_Creators.md) — platformy do nauki i twórcy
- [Toys.md](Toys.md) — sprzęt i narzędzia (z tańszymi odpowiednikami DIY)
- [scratch/README.md](scratch/README.md) — główny notatnik: narzędzia, komendy i techniki
- [BadUSB/](BadUSB/) — przykładowy firmware BadUSB (Arduino) i payloady
